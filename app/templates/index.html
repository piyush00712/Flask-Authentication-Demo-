A working authentication flow, not a mockup

Register an account, log in, and visit the dashboard. Log out, then try the dashboard again — the route protection above is real, and so is the session state shown in the status bar.

  • hashing Passwords are hashed with Werkzeug before they ever touch the database.
  • sessions Login state is tracked server-side with Flask's signed session cookie.
  • routing A login_required decorator blocks the dashboard route when signed out.
  • structure Organised as auth and main blueprints instead of one flat file.
